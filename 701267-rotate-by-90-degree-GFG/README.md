# [Rotate by 90 degree](https://www.geeksforgeeks.org/problems/rotate-by-90-degree-1587115621/1)
## Medium

Output: [[2, 5, 8],
        [1, 4, 7],
        [0, 3, 6]]Input: mat[][] = [[1, 2],
&nbsp;               [3, 4]]
