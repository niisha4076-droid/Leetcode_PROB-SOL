# [Rotate a Matrix by 180 Counterclockwise](https://www.geeksforgeeks.org/problems/c-matrix-rotation-by-180-degree0745/1)
## Medium
Given a 2D square matrix mat[][], rotate it by 180 degrees without using extra space.Note:&nbsp;You must rotate the matrix in place and&nbsp;modify the input matrix directly.Examples:Input:  mat[][] = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
Output: [[9, 8, 7], [6, 5, 4], [3, 2, 1]]Explanation:The output matrix is the input matrix rotated by 180 degrees.Input: mat[][] = [[1, 2], [3, 4]]
Output: [[4, 3], [2, 1]]Explanation : The output matrix is the input matrix rotated by 180 degrees.
